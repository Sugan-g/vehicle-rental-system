# Online Vehicle Rental System

A full-stack MERN application that allows users to browse, book, and review vehicles for rent. The system includes authentication, payment integration (Razorpay), and rental history tracking.

---

##  Tech Stack

| Layer          | Technologies                             |
| -------------- | ---------------------------------------- |
| Frontend       | React, Tailwind CSS, Axios, React Router |
| Backend        | Node.js, Express.js, MongoDB, Mongoose   |
| Authentication | JWT (JSON Web Token)                     |
| Payment        | Razorpay                                 |
| Deployment     | Vercel / Render / MongoDB Atlas          |

## ⚙️ Installation Guide

### 1️. Clone the Repository

```bash
git clone https://github.com/yourusername/vehicle-rental-system.git
cd vehicle-rental-system
```

### 2️.Setup Backend

```bash
cd backend
npm install
```

#### Create `.env` file inside `/backend`

```
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
RAZORPAY_KEY_ID=your_razorpay_key
RAZORPAY_KEY_SECRET=your_razorpay_secret
EMAIL_USER=your email
EMAIL_PASS=your password 
```

#### Start Backend

```bash
npm run dev
```

Server will start at 👉 **http://localhost:5000**

---

### 3.Setup Frontend

```bash
cd ../frontend
npm install
```

#### Create `.env` file inside `/frontend`

```
VITE_API_URL=http://localhost:5000/api
```

#### Start Frontend

```bash
npm run dev
```

Frontend runs at 👉 **http://localhost:5173**

---

### 4️.(Optional) Run Both Servers Together

If you want to run both backend & frontend with one command, install `concurrently` and update root `package.json` like this:

```bash
npm install concurrently
```

Then add this script:

```json
"scripts": {
  "start": "concurrently \"npm run dev --prefix backend\" \"npm run dev --prefix frontend\""
}
```

Now you can start both with:

```bash
npm start
```

## ✅ Common Issues

| Issue                        | Solution                                                                                         |
| ---------------------------- | ------------------------------------------------------------------------------------------------ |
| ❌ `pricePerDay` not showing | Ensure backend `Vehicle` schema has `pricePerDay` field and you send correct field in controller |
| 🖼️ Image not showing         | Use `images[0]` field from MongoDB or set fallback placeholder in frontend                       |
| 🔐 Unauthorized              | Add JWT token in Axios headers (`Authorization: Bearer <token>`)                                 |
